# Dynamic Candidate Search Web Application

A Django-based web application for dynamic candidate searches by skills, location, and job details. The platform integrates MySQL for efficient data storage and retrieval, offers real-time search functionality, and allows users to export results in CSV format for further analysis.

## Features

- **Dynamic Candidate Search**: Real-time updates to search results based on user queries.
- **MySQL Integration**: Efficient storage and retrieval of candidate data.
- **CSV Export**: Download search results for easy data portability and analysis.
